The classifier interprets free text. Eligibility decisions remain deterministic, inspectable, and reversible.

    A tiny Multinomial Naive Bayes model trained in-browser maps text to housing, education, health/access, food, caregiving, or employment.

    Apply explicit policy rules

    Each sample program has readable conditions. No black-box model decides eligibility.

    Explain every recommendation

    Matched and missing conditions are shown so the user can understand, correct, or challenge the result.
