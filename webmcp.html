Why WebMCP changes the experience

Without WebMCP, an agent must infer labels, scrape rendered text, click controls and hope the page has not changed. With WebMCP, the site publishes a stable capability contract while the human still sees every meaningful result.

01

Discover

The agent discovers typed tools such as program listing, case analysis and comparison.

02

Execute

The tool calls the same deterministic engine as the visible UI and logs the action on screen.

03

Verify

The human sees matched and missing conditions and can correct facts before taking any real-world action.

Tool surface

The implementation uses the WebMCP Imperative API with JSON Schema contracts and explicit read-only annotations where appropriate.

list_support_options

Discover the available illustrative programs, optionally filtered by category.

analyze_support_case

Run intent classification and deterministic matching, then update the visible result panel.

explain_support_option

Return matched and missing conditions for one option against a supplied profile.

compare_support_options

Rank a selected set of options without relying on UI scraping.

load_demo_case

Stage a sample case in the human interface so a person can inspect or edit it.

prepare_next_step_checklist

Produce a concise, visible checklist based on missing conditions for a selected option.
