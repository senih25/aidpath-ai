# AidPath AI — 2-minute demo script

## 0:00–0:20 — Problem
“People looking for social support often face long eligibility pages, unfamiliar language, and uncertainty about what they are missing. A generic AI chatbot can summarize text, but a black-box model should not decide whether someone qualifies.”

## 0:20–0:40 — Product
“AidPath AI uses a hybrid architecture. A small machine-learning model running entirely in the browser interprets the user’s free-text need. A separate deterministic rule engine evaluates the actual conditions and explains every match or gap.”

## 0:40–1:05 — Student scenario
1. Select **Student renter**.
2. Click **Analyze support options**.
3. Point out the detected housing intent and probability distribution.
4. Show **Student Housing Bridge** and the four matched conditions plus the missing residency document.
5. Show **Learning Access Grant** as another relevant path.

Narration: “Notice that model confidence never changes an eligibility condition. The rules are visible and each missing requirement is explicit.”

## 1:05–1:30 — Caregiver scenario
1. Select **Caregiver**.
2. Analyze.
3. Show the caregiver and access-support options.

Narration: “The same interface adapts to a different need without collecting names, IDs, addresses, or uploading the text to an AI service.”

## 1:30–1:50 — Responsible AI
Scroll to **AI where it helps. Rules where they matter.**

Narration: “This is the key design decision: AI interprets language; auditable rules decide. All processing is local, no profile is stored, and the sample programs are explicitly illustrative.”

## 1:50–2:00 — Close
“A production system could replace the demo rules with verified, versioned official sources while keeping the same privacy and explainability invariants. AidPath AI turns a confusing policy journey into a clear next step without turning eligibility into a black box.”
